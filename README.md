# Entrepots 307 Static Site

Static bilingual HTML/CSS rebuild of the public WordPress site at `https://entrepots307.com/`.

## Pages

- French: `/`, `/nos-entrepots/`, `/conseils/`, `/faq/`, `/contact/`, `/reservation-en-ligne/`
- English: `/en/`, `/en/our-warehouses/`, `/en/tips/`, `/en/faq/`, `/en/contact/`

## Notes

- Public images are copied into `assets/images/`.
- Booking and customer portal buttons point to the existing Anemone Storage partner links.
- The contact form is static and currently uses `mailto:`. For production, connect it to Formspree, Netlify Forms, Basin, or your preferred form backend.
